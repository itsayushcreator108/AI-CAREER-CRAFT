# AI Career OS 🚀

AI Career OS is a full stack career platform which I developed mainly for students and job seekers. The main purpose of this project is to bring different career preparation tools into one platform instead of using different websites for every task.

Normally a student has to use different platforms for resume checking, ATS analysis, interview preparation, coding practice, job searching, skill analysis and portfolio creation. Through this project I tried to solve this problem by creating one platform where most of these things can be accessed from a single dashboard.

The project contains both frontend and backend and also uses AI for different career related features.

---

## 📌 About The Project

AI Career OS is basically a career assistant platform where a user can manage different parts of their career preparation.

The main modules available in the project are:

- Resume Analyzer
- ATS Resume Checker
- Resume Optimizer
- Job Matcher
- Personalized Jobs
- Skill Gap Analyzer
- AI Interview Coach
- Mock Interview
- CodeQuest Coding Practice
- Coding History and Progress
- Portfolio Generator
- User Profile
- Community
- Salary Information
- Job Suggestions

The project is still under development and some features are more complete than others. Some sections are also using sample or mock data for demonstration.
